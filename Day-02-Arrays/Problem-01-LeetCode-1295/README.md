# Problem 01 — Find Numbers with Even Number of Digits

**LeetCode:** #1295

## Approach

1. Traverse the array.
2. For each number, count the number of digits.
3. Check if the number of digits is even.
4. If it is even, increase the count.
5. Return the final count.

## Example

Input:
[12, 345, 2, 6, 7896]

Output:
2

## Complexity

- Time Complexity: O(n × d)
- Space Complexity: O(1)

## Language

- C
