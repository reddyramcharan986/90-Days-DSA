# Problem 01 — Bubble Sort in Ascending Order

**Topic:** Arrays / Sorting  
**Algorithm:** Bubble Sort  
**Language:** C

## 🧠 Approach

1. Compare adjacent elements in the array.
2. If the left element is greater than the right element, swap them.
3. Repeat the comparisons for each pass.
4. After every pass, the largest unsorted element moves to the end.
5. Continue until the array is sorted in ascending order.

### Input

[5, 2, 8, 1, 3]
