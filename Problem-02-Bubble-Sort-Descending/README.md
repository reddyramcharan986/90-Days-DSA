# Problem 02 — Bubble Sort in Descending Order

**Topic:** Arrays / Sorting  
**Algorithm:** Bubble Sort  
**Language:** C

## 🧠 Approach

1. Compare adjacent elements in the array.
2. If the left element is smaller than the right element, swap them.
3. Repeat the comparisons for each pass.
4. After every pass, the smallest unsorted element moves toward the end.
5. Continue until the array is sorted in descending order.

[5, 2, 8, 1, 3]
