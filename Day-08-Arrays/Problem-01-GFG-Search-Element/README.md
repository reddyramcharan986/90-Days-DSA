# Problem 01 — Search an Element in an Array

**Platform:** GeeksforGeeks  
**Topic:** Arrays / Linear Search  
**Language:** Python

## 🧠 Approach

1. Traverse the array from the first element to the last.
2. Compare each element with the target `x`.
3. If an element matches `x`, return its index.
4. If the target is not found, return `-1`.

## 💡 Example

**Input:**
```text
arr = [10, 20, 30, 40]
x = 30
```

**Output:**
```text
2
```

## ⏱️ Complexity

- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
