# Problem 02 — Sort Array By Parity

**Platform:** LeetCode  
**Problem:** #905 — Sort Array By Parity  
**Topic:** Arrays / Sorting  
**Language:** C

## 🧠 Approach

1. Create a new array to store the result.
2. Traverse the input array and add all even numbers first.
3. Traverse the array again and add all odd numbers.
4. Return the resulting array.
