# Problem 02 — Array Search

**Platform:** GeeksforGeeks  
**Topic:** Arrays

## 🧠 Approach

1. Traverse the array from left to right.
2. Compare each element with the target `x`.
3. If the element matches `x`, return its index.
4. If the entire array is checked and the element is not found, return `-1`.

## 💡 Example

### Input

```text
arr = [1, 2, 3, 4]
x = 3
